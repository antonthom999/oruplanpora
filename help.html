Hi all, this is the help page. We are still adding and deleting stuff here.

Rotating an object - Select an object, press space. Copy objects/rooms - Ctrl C and Ctrl V works most of the time. Insert from another project - insert button lets you insert an entire project into the current one. Room Renaming - rooms can be renamed from the Room properties button. But then 'Generating new' might fall back to original name.

Can i add any png/image from internet into the current file? Yes you can, if you have its link. In the current file, create copy of an object. If you dont have any object, drag in one from the library. Then inside its properties, change the url to your image link. Adjust the sizes as you like. If you can right click over any image in internet and 'open the image in a new tab', then you should be able to add it in without much hastle. Can i create my own object library? Yes, you can. Upload all images you like (textures/pngs etc) in an image hosting site, which allows getting image links. Currently all my images(pngs) are in tumbler. Open a new file, load all images into the current file, using the method explained in previous question. You can use this as a library. Can i copy/import stuff from another file? Yes, you can. Use the 'insert contents' button, to import a file totally into the current project. The new plan will get inserted 25' below the current plan. Can i add an image from the local computer? Sorry no. The idea was to keep the file size to a bare minimum (in the range of kb). Can i save the file locally? Yes, you can. click on save button. You can also open a previously saved local file. When i open a previously saved file, there are no textures/objects. Check your internet. Internet is required for the object/images/textures to load up. When i click on library, its blank, why? Check your internet. Library might take a bit of time to load from internet. Can i adjust/remove the shadows? Yes. General Settings. Object Shadow. Opacity and Spread. Can i add more data/parameters on each of the objects? Yes, Library settings lets you add any number of parameters you like. This would apply to all objects. Data types can be text, number, integer, length, currency, yes/no and URL. How can i change my room flooring? Select a room. Click 'Room Properties' button. Paste the image link below the 'Paste image URL here'. You can find links to the architectural flooring materials from the Architextures links, right below the tile sizes. If you found an image in the internet, which you wish to put as the room flooring, check if you can right click on it and open the image in a new tab. If yes, you should also be able to copy the image link (for pasting in the room properties). How can i get high clarity/resolution images of my plans? To get high resolution on desktop site, zoom out in website (move out of the canvas space, then press ctrl minus). The more you zoom out, then more clarity image you get, then click zoom to ﬁt, then click save image. We will make a small video demo on this. How can i get this as an autocad/revit file/sketchup? We are working on this. Currently we are thinking in the direction of - creating a python shell script (so you too edit/add) which can directly open/import the oruplanpora file into revit. Any suggetions are welcome. We are working on sample projects, which you may download, modify, etc. We are also working on creating libraries with new stuff.
